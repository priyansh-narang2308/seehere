## Deliverables (CONFIRMED, Vultr page, verbatim list)
1. A public GitHub repository with setup instructions and documentation.
2. Backend deployed on a **Vultr Compute instance**.
3. A recorded demo video walking through the key features and the project running on Vultr.
4. A public demo URL with a real, product-style experience, not just a local demo.
5. A clear explanation of the use case and system design, with diagrams and screenshots of the user flow.

- **Reach:** real users, shares and votes. "Talk to users in 3+ countries."
- **Bonus:** cross-university teams and community challenges.
